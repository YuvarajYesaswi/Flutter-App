# Attendance Management System — Antigravity Phase Instructions

These files are designed to be given to an AI coding agent such as Antigravity one phase at a time.

## Recommended order

1. `PHASE_01_PROJECT_SETUP.md`
2. `PHASE_02_AUTH.md`
3. `PHASE_03_DASHBOARD.md`
4. `PHASE_04_STUDENTS.md`
5. `PHASE_05_ATTENDANCE.md`
6. `PHASE_06_PERIOD_ATTENDANCE.md`
7. `PHASE_07_FIREBASE.md`
8. `PHASE_08_REPORTS_POLISH.md`

## How to use

Give only one phase to Antigravity at a time.

Example:

> Read and execute `PHASE_01_PROJECT_SETUP.md`. Inspect the existing project first. Complete only this phase, verify the app builds/runs, and report the files changed and test result. Do not start the next phase.

After the phase is successfully completed, give the next file.

## Important

- Keep the reference screenshots available to Antigravity if its environment supports image/context input.
- The screenshots should be treated as UI inspiration, not as an instruction to reproduce a desktop table on a mobile screen.
- The application is intentionally built in stages.
- Do not let the coding agent rewrite the entire project at every phase.
- Preserve working code from earlier phases.
- Run/analyze/build after each phase.
- Firebase is intentionally delayed until Phase 7 so UI and local functionality can be verified first.
